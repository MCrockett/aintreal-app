# App Review Notes

## Login Required
No - the app works fully in guest mode.

## How to Test

**Solo Play (recommended):**
1. Launch app → Select "Classic Solo"
2. Enter any name → Tap "Create Game"
3. Tap the image you think is AI-generated
4. Complete 5 rounds to see results

**Multiplayer** requires 2 devices with matching game codes.

## Sign-In (Optional)
- Google Sign-In and Apple Sign-In available from Profile screen
- All game features work without signing in

## Ads
- Banner ads appear on home and results screens
- Interstitial ads appear after every few games
- In-app purchase ($2.99) removes all ads

## Account Deletion
Profile screen → Delete Account (or https://aint-real.com/delete-account)
